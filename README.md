# Телеграм-бот: картинки, выплаты дизайнерам, ткани

Меню бота (кнопки):

- 🎨 **Создать картинку** — бот рисует картинку по описанию (бесплатно, без ключей для рисования).
- 💵 **Выплата дизайнеру** — бот пошагово спрашивает данные и присылает готовый PDF.
- 📦 **Остатки тканей** — показывает остатки по направлениям из Google Таблицы.
- 💰 **Прайс тканей** — показывает цены по направлениям из той же таблицы.
- 👗 **Готовая продукция** — показывает готовую продукцию по направлениям.

Всё разложено по шагам ниже. Ничего программировать не нужно — только копировать и вставлять.

---

## Шаг 1. Установите Python

1. Зайдите на [python.org](https://www.python.org/downloads/) и скачайте последнюю версию.
2. Запустите установщик. **Обязательно поставьте галочку "Add python.exe to PATH"** внизу первого окна.
3. Нажмите "Install Now" и дождитесь конца установки.

## Шаг 2. Установите библиотеки

1. Откройте папку `telegram_bot` (эту самую).
2. Кликните по адресной строке папки сверху, сотрите путь, напишите `cmd` и нажмите Enter — откроется чёрное окно командной строки прямо в этой папке.
3. Вставьте команду и нажмите Enter:

```bash
pip install -r requirements.txt
```

4. Дождитесь, пока всё установится (появится новая пустая строка для ввода).

## Шаг 3. Получите токен Telegram-бота

1. В Telegram найдите **@BotFather** и откройте с ним чат.
2. Отправьте `/newbot`.
3. Придумайте имя бота (любое, по-русски).
4. Придумайте username — обязательно на английском и обязательно заканчивается на `bot` (например, `moya_shveyka_bot`).
5. BotFather пришлёт длинную строку вида `7123456789:AAH...` — это ваш токен, скопируйте его.

## Шаг 4. Получите ключ Gemini (нужен только для раздела "Создать картинку")

1. Зайдите на [aistudio.google.com](https://aistudio.google.com), войдите под своим Google-аккаунтом.
2. Нажмите **"Get API key"** → **"Create API key"**.
3. Скопируйте ключ (начинается на `AIzaSy...`).

Если пропустить этот шаг — всё остальное будет работать, а картинки бот будет рисовать чуть менее точно (без перевода промпта), но тоже будет работать.

## Шаг 5. Настройте Google Таблицу с тканями и продукцией

1. Создайте новую Google Таблицу (sheets.google.com → пустой файл).
2. Переименуйте первый лист в **`Ткани`** и заполните колонки в первой строке ровно так:

   | Направление | Название      | Остаток      | Цена         |
   |-------------|---------------|--------------|--------------|
   | Верхняя одежда | Кашемир серый | 45           | 1200         |
   | Верхняя одежда | Шерсть чёрная | 12           | 950          |
   | Платья      | Шёлк белый     | 8            | 1800         |

   («Направление» — это категория/линейка, по которой бот будет группировать список.)

3. Создайте вторую вкладку снизу, назовите её **`Продукция`**, колонки:

   | Направление | Название         | Цена  | Наличие      |
   |-------------|------------------|-------|--------------|
   | Платья      | Платье "Ирис"    | 6500  | Готово       |
   | Верхняя одежда | Пальто "Вельвет" | 14000 | Под заказ    |

4. Для **каждой** из двух вкладок отдельно сделайте публикацию в интернет:
   - Откройте вкладку (например, "Ткани").
   - Меню **Файл → Поделиться → Опубликовать в интернете**.
   - В первом выпадающем списке выберите именно эту вкладку (не "Всю книгу").
   - Во втором списке выберите **"Значения, разделённые запятыми (.csv)"**.
   - Нажмите **"Опубликовать"**, подтвердите.
   - Скопируйте появившуюся ссылку — она пригодится в Шаге 6.
   - Повторите то же самое для вкладки "Продукция".

   Эта ссылка доступна только тем, у кого она есть (не показывается в поиске), но всё же не является полностью приватной — не пишите в эту таблицу секретные данные.

5. Дальше вы редактируете эту таблицу как обычно (добавляете строки, меняете цены) — бот всегда подтягивает свежие данные при нажатии кнопки (Google обновляет опубликованный CSV примерно раз в 1–5 минут).

## Шаг 6. Заполните файл настроек

1. В папке `telegram_bot` найдите файл `.env.example`.
2. Сделайте его копию и переименуйте копию в `.env` (без `.example`).

   > Если не видно расширений файлов: откройте папку → вкладка "Вид" → поставьте галочку "Расширения имён файлов".

3. Откройте `.env` через Блокнот и вставьте свои значения после знака `=` (без кавычек, без пробелов):

```
TELEGRAM_BOT_TOKEN=7123456789:AAH-ваш_токен
GEMINI_API_KEY=AIzaSy-ваш_ключ
FABRICS_CSV_URL=ссылка_на_CSV_вкладки_Ткани
PRODUCTS_CSV_URL=ссылка_на_CSV_вкладки_Продукция
COMPANY_NAME=Название вашей компании
```

4. Сохраните (Ctrl+S) и закройте.

## Шаг 7. Запустите бота

1. В том же чёрном окне командной строки (из Шага 2) введите:

```bash
python bot.py
```

2. Если курсор просто мигает на пустой строке без ошибок — бот запущен и работает.
3. Не закрывайте это окно — пока оно открыто, бот в сети. Чтобы остановить бота, нажмите `Ctrl + C`.
4. Откройте Telegram, найдите своего бота по username и нажмите **Start** (`/start`).

## Как редактировать бота дальше

- Остановите бота (`Ctrl + C` в чёрном окне).
- Внесите правки в файлы (`bot.py`, `keyboards.py`, тексты сообщений и т.д.) через любой редактор кода.
- Сохраните и снова запустите `python bot.py`.
- Ткани/продукцию/цены менять программированием не нужно вообще — правьте прямо в Google Таблице.

## Если что-то не работает

- **`ModuleNotFoundError`** — не выполнен Шаг 2, повторите `pip install -r requirements.txt`.
- **`TokenValidationError` / бот не отвечает** — проверьте, что в `.env` токен скопирован полностью, без лишних пробелов и кавычек.
- **"Ссылка на таблицу не настроена"** — не заполнены `FABRICS_CSV_URL` / `PRODUCTS_CSV_URL` в `.env`, или в таблице не опубликована нужная вкладка.
- **"Не найдены колонки Направление и Название"** — проверьте точные заголовки первой строки в таблице (см. Шаг 5).
- **PDF без кириллицы (квадратики)** — на компьютере не нашёлся шрифт с русскими буквами; убедитесь, что бот запущен на Windows (там используется системный Arial), либо положите файл `DejaVuSans.ttf` в папку `telegram_bot/fonts/`.
