# Телеграм-бот: картинки, выплаты дизайнерам, ткани

Меню: 🎨 Создать картинку · 💵 Выплата дизайнеру · 📦 Остатки тканей · 💰 Прайс тканей · 👗 Готовая продукция.

Данные по тканям и продукции бот берёт из Google Таблицы (вкладки «Ткани» и «Продукция»).
Ссылки на неё вписаны в `config.py`; правьте таблицу — бот показывает свежие данные.

## Запуск в облаке (Vercel, бесплатно, без карты)

1. vercel.com -> войти через GitHub -> Add New -> Project -> выбрать этот репозиторий -> Deploy.
2. Project -> Settings -> Environment Variables: добавить `TELEGRAM_BOT_TOKEN` (и по желанию `GEMINI_API_KEY`).
3. Deployments -> Redeploy (чтобы переменные применились).
4. Один раз откройте в браузере `https://<ваш-проект>.vercel.app/api/setup` — бот подключится к Telegram.

Бот «спит», пока нет сообщений, и просыпается от первого сообщения.

## Запуск на компьютере

    pip install -r requirements.txt
    python bot.py

Токен — в файле `.env` (см. `.env.example`).

## Выплата дизайнеру

Нажмите кнопку и ответьте на сообщение бота пятью строками: ФИО, заказ, сумма, дата (или «сегодня»), реквизиты.
